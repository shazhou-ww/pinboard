# Deployment

本契约仅为后续现实验证的初版，没有部署或发布授权。当前不改生产配置，不启用推送部署，不发布连接器。

## Steps

### D-S01: 在获准环境验证取数节点链路

取得明确授权后，在隔离环境验证真实网络下的连接、休眠唤醒、重连、节点切换、凭证撤销、租约恢复及真实 delegate 的连通性。

### D-S02: 验证 Kubo 工作流并限定发布声明

使用受控账号与本地独有数据验证远程 pin、失败查询及来源和执行节点均停止后的 HTTP 读取；依据实际证据说明不可变快照、引用保留和发现范围，不宣称文件自动同步。

## Acceptance criteria

### D-AC01: 真实连接与授权行为符合约定

保留获准环境中的连接、重连、任务转交、撤销、delegate 可达性和跨账号隔离验证记录；日志不包含凭证或内容字节。

### D-AC02: 远程 Pin 结果可以独立复核

记录目标 Kubo 版本下的成功与失败请求，并在停掉来源和执行节点后验证下载内容相同；公开说明实际支持范围，不把 HTTP 可读等同于公共 P2P 自动发现，也不把客户端可用表述为未经证实的严格标准兼容。
