# Deployment

准备阶段的轻量外部验证初版；本次记录构想不授权部署、生产迁移或发布标签。

## Steps

### D-S01: 确认授权环境和上线前提

依现有部署指南确认目标环境、数据保护和回退条件；生产 D1 迁移与生产发布分别取得明确授权。

### D-S02: 在授权环境验证发布闭环

使用真实访问链路验证两种发布入口、固定链接、当前链接、回滚、协商缓存和撤销，并确认现有 Pin 与 Token 行为。

### D-S03: 核验引用存活和运维可见性

在隔离测试数据上验证 Unpin 后的发布存活及最后引用释放语义，检查发布失败与 GC 异常的可定位证据。

## Acceptance criteria

### D-AC01: 发布遵循现有授权与上线流程

记录目标版本和环境；如涉及生产，提供独立迁移授权和符合标签驱动流程的发布证据，不以本 idea 代替授权。

### D-AC02: 实际客户端访问符合发布约定

保留真实 HTTP 状态、ETag 和客户端结果，证明发布与回滚更新当前入口、固定内容不变、未变化响应为 304、撤销不返回旧状态的 304。

### D-AC03: 已发布内容不因普通 Unpin 丢失

用隔离数据的读回结果、引用状态和清理日志证明发布引用保护内容，释放最后引用才进入宽限期；不对生产有效内容执行破坏性清理测试。
