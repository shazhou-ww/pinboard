# Implementation

## Steps

### I-S01: 明确记录来源与安全存储契约

基于实际 IPNS 依赖及部署条件确认来源、写入授权、版本比较和持久化策略；涉及实质取舍时先完成对应决策，不默认新增 DHT 或匿名导入。

### I-S02: 实现记录响应并验证互操作

增加原始记录协商、有效期和版本校验，使用独立验签与重启 fixture 验证；同步文档并运行 pnpm
check。

## Acceptance criteria

### I-AC01: 名称绑定与版本规则可证明

独立客户端能验签有效记录，负例覆盖篡改、错名、过期和版本回退；持久化测试证明重启不会丢失已见版本约束。

### I-AC02: HTTP 与授权边界一致

GET/HEAD、协商、条件缓存、来源失败与无记录测试通过；不存在未授权写入或 raw/CAR 回归，pnpm
check 通过。
