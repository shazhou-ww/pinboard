# Deployment

## Steps

### D-S01: 验证标准客户端范围读取

独立客户端分别请求多块文件、普通/HAMT 目录、内联值和子 DAG，验证内容重建、准确 block 集合及默认 all，不能只检查响应状态。

### D-S02: 按授权检查目标环境兼容性

本轮用户已在方案接受后另行明确授权继续实施、由父 Agent 负责门限审批、生产发布及 Chrome 冒烟；这不追溯改写 Ideal 中先前的仅规划决定，也不沿用前两轮授权。实施子 Agent 只负责本地候选及验证，不提交、不推送、不变更生命周期、不发布。父 Agent 按部署指南检查目标环境的默认 all、各 scope、权限、条件请求和旧接口，使用 CDP
127.0.0.1:19302 完成 Chrome 冒烟。生产 schema 操作和迁移不在授权内。

## Acceptance criteria

### D-AC01: 范围效果可以外部复核

记录客户端版本、请求、CID 集合、重建哈希与目录清单，证明 entity 未递归包含子文件、内联 all 未包含兄弟子图；独立离线客户端可验证所请求范围，删除或篡改必要块会失败。

### D-AC02: 环境声明与结果一致

获准目标版本的权限、条件请求、取消与失败语义验证可复现，包括已初始化业务环境中的临界合法范围读取；明确本地及生产结论，不将源码检查当作线上证明，也不未经授权执行生产迁移或发布。
