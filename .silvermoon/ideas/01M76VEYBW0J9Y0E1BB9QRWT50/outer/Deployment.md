# Deployment

## Steps

### D-S01: 在隔离环境复验标准互操作

运行固定官方套件和冷缓存独立客户端，以 TLS/HTTP2 验证实际链路；资源实验仅针对获准的隔离目标。

### D-S02: 按授权形成目标环境声明

2026-11-12 最新授权仅限计划更新与隔离可行性实验，不授权生产实现或部署；父会话处理全部门限，执行子会话不提交、同步、修改生命周期或部署。本次共槽受控串行化仍超过固定内存门槛，停止后续实现和外部验证，不能据此推进发布。

若将来另获授权且可行性及验收满足，仍须按部署指南验证获准目标版本和观测链路，保持现有 tag 驱动的生产发布流程。压力实验仅留在获准隔离环境，不执行数据库迁移或购买基础设施，不把本地结果升级为线上结论。账户只读信息的
`usage_model: standard`、Worker `limits: null` 不能确认 Free/Paid；subscription
API 403，计划及 CPU/D1 有效配额仍未证实。本轮不再访问账户配置、凭据或云控制面。

## Acceptance criteria

### D-AC01: 外部兼容性可复现

记录环境、版本、请求、官方结果与内容校验；支持矩阵的通过和排除均能追溯到证据。

### D-AC02: 实际运行保障有证据

在获准环境中验证预定阈值、限流响应、资源回收及业务可用性；公开声明准确区分生产、隔离及未验证项目。
