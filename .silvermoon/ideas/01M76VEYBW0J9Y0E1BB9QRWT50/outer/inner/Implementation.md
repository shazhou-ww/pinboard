# Implementation

## Steps

### I-S01: 建立可复现的官方一致性检查

固定上游版本和测试选择，建立规范到测试的支持矩阵，修复声明范围内缺口并同步文档。

### I-S02: 固定预算并验证 Worker 隔离

在测试前明确负载与通过阈值，验证 D1/R2 操作、并发、取消、故障观测及业务接口隔离，运行 pnpm check。

## Acceptance criteria

### I-AC01: 合规声明有独立证据

官方套件及独立客户端结果与固定版本、配置和排除理由关联；缓存、路径、浏览器及权限边界无未解释失败。

### I-AC02: 资源阈值实测达标

负载与故障实验记录事先确定的数值阈值及实测值；取消后资源回收、业务可用性和 pnpm check 均通过，不在失败后放宽门槛。
