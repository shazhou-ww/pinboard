## 协议支持与独立检查

官方 gateway-conformance 基准采用 v0.14.1，release 对应 commit
`011d20bd61c4736e3301d35e8fe388773e492511`。执行前核实 tag 指向并固定套件、fixture 和适用测试清单，不采用滚动 latest。对 raw、CAR、可选 CAR 子集及 path 行为逐项映射规范与测试；缺失、失败、排除和通过分开记录，不能用大类跳过隐藏已声明能力失败。

本轮保留 CARv1/dfs/n、三个 scope、entity-bytes 及现有授权模型；不增加 raw HTTP
Range，明确记录不支持及实际整块响应，不承诺 206/416。IPNS、dups=y、CARv2、DNSLink、网站托管仍排除。完整客户端兼容性不是实现全量 Path
Gateway。

浏览器验证需区分公开匿名 raw/CAR 的 CORS/预检和私有同源读取；不以兼容性为由放开跨站 Cookie、共享缓存、私有内容或允许根 service
worker。必要 HTTP 修正须列明行为变化和独立证据。iteration 4 已记录 Kubo
v0.43.1 对中间内联数据的偏差：完整参考 DAG 也有同样偏差，不标为网关通过或通过删减合法 fixture 隐藏。

## 已确认的初始资源方案

| 项目               | 固定方案或目标                                           |
| ------------------ | -------------------------------------------------------- |
| CAR 预检接纳       | 每个 Worker isolate 同时最多 1 个；GET/HEAD/304 共用预算 |
| 超额请求           | 不排队，快速 429，提供 Retry-After                       |
| Retry-After 初始值 | 1 秒；只提示重试，不保证届时有空位                       |
| 请求总期限         | 180 秒，包含预检及响应传输；成功前完整性语义不变         |
| 隔离并发实验       | 同时发起 4 个保持占用的大 CAR 请求，最多接纳 1 个        |
| 超额拒绝期限       | 从服务端收到请求起，1 秒内返回拒绝                       |
| 取消后恢复         | 取消在服务端被观测后，1 秒内可接纳新请求                 |
| 业务隔离           | 同机健康及授权探测零失败，p95 ≤ max(基线×2, 基线+200 ms) |

上表针对 CAR 预检，不把已有 raw 元数据 HEAD 改为全量读取，也不把 private/no-store 换成跨用户缓存。采用保守的所有 CAR 共用单槽，避免先完整读 DAG 才判定“大请求”；若后续提出小请求分级、排队或不同 admission 策略，应先讨论。429 不替代 404 权限隐藏或成功 304 的前置验证；格式/授权拒绝与接纳顺序必须通过无存储读取断言确认。

单槽是 isolate-local 接纳限制，不是全局限流、账户配额、跨实例锁或全站内存上限。Cloudflare 可以启动多个 isolate；不能以本地 occupied 变量承诺全球只有一项请求。不引入 Durable
Object、D1 锁或付费基础设施来伪装成同一方案。

总期限不是性能目标：已有近界生产预检约 109–121 秒，保留 180 秒只是初始安全边界，不宣称优化时延。超时前未提交响应则显式失败；提交后不能改状态，应中止流并让客户端判定不完整。不得提前释放尚被响应体持有的预算，或因客户端未继续读取而永久占用；取消、异常、正常 EOF 和传输超时都须完成释放。网络请求对象未传播的断连不能被当作已观测取消，须区分平台事件与测试注入。

## 测量方法与未证实事项

- 隔离压力实验至少复现 3 次，并同时记录冷/暖、fixture 大小、唯一块数、接纳/拒绝结果和 service-side 时间；业务探测每种至少 100 次，基线与负载在相同环境和采样间隔执行，p95 算法固定。
- 使用受控阻塞 fixture 保持单槽占用以避免“4 个请求恰好串行完成”产生假通过；另用真实近界 DAG 证明合法输入和资源成本，测试逻辑不能代替实际内容读取。
- 既有限额仍为 256 个唯一块、32 MiB 载荷、单块 2
  MiB；预检的 D1/R2 操作、内存、native
  arena 及未读响应持有要分别测量。本地绑定计数不是生产平台 traces，V8 采样不是精确峰值。
- 1 个大 CAR 与 PDF/图片实际渲染并存时的联合内存尚未证明安全；不能用“预先初始化 arena”冒充“并发渲染安全”。若失败，先返回方案讨论，不静默改变预览 UX、放宽内存或降低合法输入上限。
- 180 秒期限、客户端断连通知、流中止及占用释放须在真实 workerd 中验证，发布前核对目标 Workers 计划的 CPU/内存/子请求约束，不假设本地成功等同线上配额足够。

固定目标不得在失败后放宽来完成门限。若平台可行性与已确认目标冲突，记录准确结果并重新讨论，不将“已配置限流/超时”视为已达成运行保障。
