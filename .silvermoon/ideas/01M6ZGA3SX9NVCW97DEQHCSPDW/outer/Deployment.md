# Deployment

## Steps

### D-S01: 确认上线与迁移前提

按仓库部署指南确认存量策略、回退风险及缓存处理，取得独立的生产发布和 D1 迁移授权；构想验收不授权部署。

### D-S02: 执行授权发布与缓存处理

仅在获准后执行所需迁移、标签驱动发布及可控 CDN 缓存清理，告知既有浏览器缓存和外部副本无法收回。

### D-S03: 验收真实访问边界

在获准环境用两个账号、匿名客户端和受限 Agent 验证公开／私有切换、共享内容、历史版本及下载，记录可复核外部证据。

## Acceptance criteria

### D-AC01: 上线策略有据可查

发布、迁移及缓存操作有明确授权和可核对记录，存量内容符合已确定策略；以部署记录与抽样读取证明。

### D-AC02: 私有内容仅授权身份可读

真实请求证明作者及其授权 Agent 能读取，其他账号、匿名和低权限凭证不能读取私有项及历史；覆盖预览、原文件、ZIP、CAR 和块入口。

### D-AC03: 公开切换符合承诺

真实共享 CID 和公开转私有请求证明最后一个公开引用取消后，服务端停止新的匿名读取；可控 CDN 无旧公开命中，外部副本不作撤回承诺。
