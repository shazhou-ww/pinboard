# Implementation

## Steps

### I-S01: 定义逐项权限与兼容策略

明确 Pin、Publication、合法引用和完整 DAG 的授权规则，设计默认私有及存量公开项迁移，保留账号隔离和恢复语义。

### I-S02: 贯通读取与管理入口

落实权限存储及服务端校验，覆盖下载、块、预览、版本、元数据和引用操作；同步 Web、CLI、MCP、共享契约及文档，区分账号会话、Agent 和 MCP OAuth 的现有凭证边界。

### I-S03: 验证隔离与公开兼容

添加跨账号、共享 CID、历史版本、引用及缓存行为测试，执行针对性验证和仓库要求的 `pnpm check`。

## Acceptance criteria

### I-AC01: 权限状态一致

通过契约和客户端测试证明新建默认私有、逐项切换和风险提示一致，更新与回滚不改变权限，存量策略有对应迁移测试。

### I-AC02: 私有访问无读取旁路

通过账号 A／B、匿名和受限凭证测试证明私有内容树、缩略图、描述及历史不可越权读取，HEAD／304 和凭 CID 引用、单块补齐不会绕过授权。

### I-AC03: 共享内容与缓存符合规则

通过共享 DAG 和公开转私有测试证明仅公开引用允许匿名读取，私有项元数据独立隔离，权限校验先于条件响应且受保护响应不进入公开缓存；完整检查通过。
