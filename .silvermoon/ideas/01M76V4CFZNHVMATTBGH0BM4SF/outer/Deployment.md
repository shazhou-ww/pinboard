# Deployment

## Steps

### D-S01: 验证独立客户端 raw 互操作

在隔离环境使用冷缓存 Kubo，经 TLS/HTTP2 读取已授权的测试 DAG，关闭源节点并校验内容。

### D-S02: 按授权验证目标环境

用户已授权本轮生产部署及由 Agent 执行门限审批。按部署指南，在主线 CI 通过后以新的 release
tag 发布，不改变触发方式、不执行数据库迁移。使用用户提供的 Chrome for
Testing 调试端口验证生产页面、会话及 raw 协议，创建专用临时 Pin 校验权限、字节与 CID，验证根注册拒绝后清理该 Pin。

## Acceptance criteria

### D-AC01: 冷缓存检索可独立复现

记录环境版本、探测与逐块请求，以及重建文件哈希；没有向其他来源回源。

### D-AC02: 外部行为与声明一致

生产发布成功且精确 tag、commit、工作流可追溯；Chrome for
Testing 实测页面、身份、私有内容拒绝、公开读取、GET/HEAD、条件响应及根注册拒绝，独立校验返回字节对应 CID。记录浏览器及实际 HTTP 协议，清理专用测试 Pin；本地 Kubo 证据与生产浏览器证据分开陈述，不据此宣称全功能网关兼容。
