# Implementation

## Steps

### I-S01: 明确 raw 与授权行为矩阵

对照固定规范版本，记录协商、权限隐藏、缓存、缩略图和浏览器请求边界；复用现有处理器并仅修复实际缺口。

### I-S02: 补齐实现与回归验证

针对行为差异增加聚焦测试，同步 README 与 Kubo 文档，执行相关测试及 pnpm check。

## Acceptance criteria

### I-AC01: 协议行为与权限一致

用真实 Worker 路由测试 GET/HEAD、条件响应、探测和不同可访问性状态；未授权请求在存储读取前被拒绝。

### I-AC02: 数据及既有体验不回归

独立 CID 校验及图片访问测试通过；文档与响应矩阵逐项一致，pnpm check 通过并留存结果。
