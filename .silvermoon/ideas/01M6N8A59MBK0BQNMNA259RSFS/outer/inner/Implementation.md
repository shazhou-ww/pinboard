# Implementation

体验目标以[构想契约](ideal/Idea.md)及其内容预览约定为准。本次使用现有 Worker、D1 与 R2，不启用 Images
binding 或外部图片服务。实现证据、复验入口与实际检查结果见
[Verification.md](Verification.md)。

## Steps

### I-S01: 定义按 CID 共享的预览存储与接口

D1 迁移 `0005_previews.sql`
保存按原 CID 与版本共享的状态及类型描述；`preview_images`
以缩略图 CID 为键保存真实 BLOB，不存 Base64 或账户 Pin 名称。描述使用共享的
`contentType` / `content`
判别联合，四种状态独立表达。图片长边不超过 480 像素，WebP 字节不超过 64
KiB；按原始 WebP 字节计算 SHA2-256 raw CID，`/ipfs/{thumbnailCid}`
直接交付图片而非 CAR，保留显式 raw 协议入口及独立缓存验证器。列表不包含图片字节。

多原内容、多账户、直接 Pin 缩略图及包含缩略图块的 DAG 都可形成有效引用。每个源保留最近发布的
`active`
版本，新版本待生成或失败时不提前撤销旧引用；新版本发布及旧版本退役在同一事务完成，过期 Worker 不能覆盖更高的已发布版本。更新引用与 D1 图片回收在事务中重新检查存活关系；Unpin 或版本切换后提供七天保留期。

发布前查询整个已验证 DAG 中已知缩略图的 CID 与尺寸；已有 DAG 的 Pin 在遍历前也保留其已知成员快照。直接或间接引用在 R2 写入期间与回收竞争时，使用 DAG 内已验算 CID 的对应块，在发布新 Pin 的同一事务重新保存图片 BLOB，而非只保护根 CID。旧版本元数据与无引用图片分批清理，不自动创建账户 Pin。

### I-S02: 实现受限、可重试的内容预览生成

在现有 Worker 中使用预编译的 jSquash
JPEG、PNG、WebP 解码与 WebP 编码 WASM，避免运行时编译、原生 Node 扩展和付费绑定。输入限 8
MiB
/ 二百万像素；先检查尺寸，再解码，按透明度加权缩小，依次尝试 480/72、480/45、320/40、240/30 的长边与质量，仍超过 64
KiB 则失败。

仅读取本地已存储且逐块验证的 UnixFS 根内容；一次任务最多读取 64 块及 12
MiB。文本读取至多 10,000 字节前缀，按 Unicode 字符截取 2,400 字，普通标点转义，结构化文本使用忠实代码围栏；不把名称作为格式依据，不虚构标题或总结。目录读取至多 24 个实际条目、两个条目层级，仅完整遍历时报告已验证的顶层总数；首版不附加可选子图。PDF、GIF、音视频及未知内容明确占位，不执行 HTML/SVG 或读取远程资源，不展示 DAG 图。

Pin 保存后入队，通过 `waitUntil`
执行。两分钟租约及唯一令牌隔离重复/过期任务，每版本至多三次尝试并退避；现有小时任务每轮至多处理两个任务及发现两个缺失预览。回收每批最多删除 50 个图片或元数据记录。生成及入队失败显式记录，不撤销成功的 Pin；最后一次执行中断也会转为明确失败。

### I-S03: 接通内容墙与全部内容来源

Web、CLI、API、MCP 的文件、CAR、块导入和已有内容 Pin 统一进入
`PinService`。旧 Pin 可由小时任务或受授权的 `/api/pins/:cid/preview`
懒补生成。该接口在共享记录读取之前验证账户所有权与
`pins:read`，返回私有、不可缓存的描述；缩略图网关沿用按 CID 公开读取。

内容墙只在卡片进入视口时读取描述，待生成状态最多追加七次轮询；移除浏览器 CAR 重建代码。类型化渲染仅显示真实缩略图、惰性文本/代码、只读目录概览或明确占位，图片交付错误不触发原内容回退。保留名称/CID/大小底栏、完整 CID 复制、详情、改名、上传及 Unpin。更新 README，并提供与父会话服务器隔离的浏览器复验夹具。

## Acceptance criteria

### I-AC01: 预览存储与网络开销受限

Miniflare
D1 测试证明 BLOB 类型、共享记录不含私有标签、列表无 BLOB/Base64，真实生成字节不超过 64
KiB；图片网关响应重新计算 raw
CID，与描述一致。验证图片、raw、HEAD、ETag/304 和私有描述缓存策略。隔离浏览器网络检查证明六张卡片只读取描述及三个缩略图，无原始 CAR、raw 或外部资源请求；明确待生成与交付失败状态。

### I-AC02: 各类内容有真实且安全的预览

实际 workerd 中编码并独立解码 NASA 照片、透明 RGBA 图和纵向照片，验证尺寸、颜色复杂度与透明度；额外使用高熵 RGBA 输入验证真实降质/降尺寸路径，而非只测小图或模拟编码。验证 PNG/JPEG/WebP 来源、畸形和像素炸弹输入。文字、代码、中文/Emoji、HTML/SVG、外链、含图片目录、分块文件、UnixFS
CAR 与伪造扩展名覆盖忠实性、精确截断、只读概览和无主动内容；普通 `.car`
上传不自动重导入。

### I-AC03: 所有入口与 Pin 生命周期保持一致

集成测试覆盖各上传来源、已有内容补生成、重复任务、重试、入队失败恢复、改名、详情、Unpin 与共享引用清理，包括不同原内容生成同一缩略图、多账户、直接 Pin、DAG 成员引用、版本切换，以及暂停 R2 写入期间与 GC 的实际竞争。仅在所有有效引用消失且七天届满后回收；既有授权、原 CID 与字节不变。执行
`pnpm check`
并记录实际结果；已有 Windows 凭据权限或 CLI 打包环境失败不伪称通过，也不作为本次修复范围。
