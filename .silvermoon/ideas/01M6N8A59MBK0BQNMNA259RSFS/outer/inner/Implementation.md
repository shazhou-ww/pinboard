# Implementation

本契约为准备阶段的可调整初版。体验目标以[构想契约](ideal/Idea.md)及其内容预览约定为准。

## Steps

### I-S01: 定义按 CID 共享的预览存储与接口

D1 保存预览状态、生成版本、类型描述及图片 BLOB；不存 Base64，不混入账户 Pin 名称。图片暂定长边不超过 480 像素、WebP 编码及 64
KiB 硬上限，其他概览使用受限的类型化数据。列表只返回轻量描述，图片通过独立、可缓存的接口交付。

### I-S02: 实现受限、可重试的内容预览生成

优先复用现有 Worker 处理生成任务，而非立即增加独立部署服务。为图片、文本、目录和已导入 CAR 的根内容设计对应生成器；明确解码、像素、条目和结构采样上限。缩略图超限时降低质量或尺寸，仍不合格则报告失败；不把异步生成失败当成上传失败。

### I-S03: 接通内容墙与全部内容来源

覆盖 Web、CLI、API、MCP 及已有 Pin 的预览获取或补生成路径，替换浏览器完整 CAR 解码。保留当前卡片信息条和详情操作，明确待生成、不支持、失败和可重试状态；更新共享契约、测试和相关文档。

## Acceptance criteria

### I-AC01: 预览存储与网络开销受限

迁移和接口测试证明相同 CID 共享预览、私有标签不进入共享记录、图片字节不超过 64
KiB，列表不携带 BLOB。浏览器网络测试证明内容墙只请求预览而非原始 CAR，并验证缓存及未生成状态。

### I-AC02: 各类内容有真实且安全的预览

用复杂照片、透明图、纵向图、文本、含图片目录、UnixFS
CAR 和通用 DAG 样本验证对应表现、准确采样标识及结构上限。测试畸形或超限内容、HTML/SVG 和伪造扩展名，证明失败明确且不执行上传内容。

### I-AC03: 所有入口与 Pin 生命周期保持一致

集成测试覆盖各上传来源、已有内容补生成、重复任务、重试、改名、详情、Unpin 和共享引用清理。既有授权、原 CID 与字节不变；预览清理不得提前破坏其他引用。运行项目检查并记录实际结果，不把环境阻塞描述为通过。
