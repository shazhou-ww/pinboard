# Deployment

本文件是准备阶段的轻量初版，不授权生产发布或数据库迁移。发布遵守[部署指南](../../../../docs/deployment.md)，不得以本 Idea 的文档同步代替发布授权。

## Steps

### D-S01: 确认发布与兼容窗口

在获得发布授权后，确认前后端协议过渡、旧页面兼容窗口和可回退产物，沿用现有 tag 驱动的发布流程；若实施证明需要 schema 变更，单独取得迁移授权。

### D-S02: 验证真实环境展示与恢复

在获准环境验证普通图片、文本、目录、无物料文件及已具备生成能力的 PDF；检查私有 Pin 与公开 Publication 的新旧客户端、缓存刷新和失败提示，记录外部验收证据。

## Acceptance criteria

### D-AC01: 发布版本与兼容边界可核验

以发布记录、响应协议版本和新旧页面实测证明部署版本一致、过渡窗口有效、回退路径可用；未获授权时不执行生产发布。

### D-AC02: 线上物料与图标切换符合约定

以真实 API 响应及浏览器证据证明物料优先、未知类型图标、失败提示和缓存升级正常；PDF 仅在对应生成能力已部署时验收首页，不将模拟视频首帧当作实际生成能力。
