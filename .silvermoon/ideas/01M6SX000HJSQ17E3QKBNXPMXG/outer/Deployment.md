# Deployment

本文件是准备阶段的轻量初版，不授权生产发布或数据库迁移。发布遵守[部署指南](../../../../docs/deployment.md)，不得以本 Idea 的文档同步代替发布授权。

## Steps

### D-S01: 确认发布与过渡条件

实施完成且获得发布授权后，核对实施阶段确定的客户端过渡及退出条件、可回退产物，沿用既有发布流程。不在本契约另定义协议协商机制。

### D-S02: 验证真实环境展示与恢复

在获准环境按[设计验证矩阵](./inner/ideal/03-Normalized-preview-design.md)检查真实响应、页面、缓存刷新和失败恢复，记录外部验收证据，不将模拟视频样例当作生成能力。

## Acceptance criteria

### D-AC01: 发布版本与兼容边界可核验

以发布记录、实际响应和已确定的消费者实测证明部署产物一致、过渡条件满足、回退路径可用；未获授权时不执行生产发布。

### D-AC02: 线上物料与图标切换符合约定

以真实 API 响应及浏览器证据证明有物料时的类型语义、无物料时的封面和失败恢复符合设计；PDF 首页仅在对应生成能力已部署时作为真实样例验收。
