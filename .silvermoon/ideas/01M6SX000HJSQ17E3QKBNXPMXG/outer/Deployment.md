# Deployment

本文件是准备阶段的轻量初版，不授权生产发布或数据库迁移。发布遵守[部署指南](../../../../docs/deployment.md)，不得以本 Idea 的文档同步代替发布授权。

## Steps

### D-S01: 确认发布与一次性切换

实施完成且获得发布授权后，核对新前后端产物、生成版本及缓存切换，按需要执行另行获准的一次性预览数据处理，沿用既有发布流程。不设置旧客户端兼容窗口，也不承诺旧应用对新预览数据的兼容回退。

### D-S02: 验证真实环境展示与恢复

在获准环境按[设计验证矩阵](./inner/ideal/03-Normalized-preview-design.md)检查真实响应、悬浮纸页、客户端刷新和图标 fallback，记录外部验收证据，不将模拟视频样例当作生成能力。

## Acceptance criteria

### D-AC01: 发布版本与一次性切换可核验

以发布记录、实际响应和刷新后的客户端实测证明新产物一致、旧缓存不混读、必要的一次性处理仅影响预览派生数据；不以跨版本回退兼容作为 MVP 门槛，未获授权时不执行生产操作。

### D-AC02: 线上物料与图标切换符合约定

以真实 API 响应及浏览器证据证明 PDF 呈现为悬浮纸页，图片加载失败正常回类型图标且不新增失败提示，物料可用后恢复；PDF 首页仅在对应生成能力已部署时作为真实样例验收。
