# Implementation

本文件是准备阶段的轻量初版。实施前置条件：[PDF 首页预览](../../../01M6SSPF59MS6DY1MV1JWFZD4N/outer/inner/ideal/Idea.md)完成实施、通过验证并合入主线；条件满足前只维护文档，不开始本项编码。届时基于实际代码细化下述步骤，不以本文件或提交记录推断 PDF 已完成。

## Steps

### I-S01: 统一协议与兼容转换

前置条件满足后，刷新[现状基线](./ideal/02-Current-preview-protocol.md)，核实消费者并确定最小过渡策略及退出条件；再依据[3 号设计](./ideal/03-Normalized-preview-design.md)统一契约、描述组装和 API 消费边界，不改变格式渲染器职责。

### I-S02: 接入共享展示与缓存

按设计接入共享物料展示、类型封面、状态联合校验和缓存结构切换；覆盖 Pin、Publication、节点详情及开发样例，不复制 PDF 渲染逻辑。

### I-S03: 验证兼容与失败路径

按设计验证矩阵运行针对性测试、浏览器检查和仓库
`pnpm check`，保留已有展示与内容安全行为。

## Acceptance criteria

### I-AC01: 协议可独立表达类型和物料

以类型校验、描述生成及 API 测试证明原类型与物料可独立表达，非法状态组合被拒绝，PDF 渲染器没有新增对公开协议的依赖。

### I-AC02: 所有展示入口一致降级

以组件测试和浏览器检查证明三类入口均物料优先、空物料显示图标，生成失败与图片加载失败仍可识别；文本、目录、长名称和暗色模式保持可用。

### I-AC03: 缓存升级与现有行为可回归

以重建、缓存及已确定的客户端过渡测试证明旧结构不会混读、旧 unsupported 不永久遮挡新物料、授权失效移除旧展示；`pnpm check`
通过。
