# Implementation

本文件是准备阶段的轻量初版，以[同步后的现状](./ideal/02-Current-preview-protocol.md)和已合入的 PDF 实现为基线。本轮只更新文档；确定悬浮纸页、直接切换协议和正常 fallback，不等于开始编码或部署。

## Steps

### I-S01: 统一协议与一次性切换

依据[3 号设计](./ideal/03-Normalized-preview-design.md)统一契约、描述组装和所有 API 消费边界，复用现有生成版本重建机制，完成缓存一次失效；必要的数据处理限定为预览派生数据，不维护旧协议兼容，不改变格式渲染器职责。

### I-S02: 接入共享展示与缓存

按设计接入共享渲染和外层布局，采用 PDF 悬浮纸页；无物料或图片加载失败时显示类型图标，不新增预览失败提示 UX。覆盖 Pin、Publication、节点详情及开发样例，不复制 PDF 渲染逻辑或新增类型专用协议。

### I-S03: 验证升级与展示规则

按设计验证矩阵运行针对性测试、浏览器检查和仓库
`pnpm check`，保留已有展示与内容安全行为。

## Acceptance criteria

### I-AC01: 协议可独立表达类型和物料

以类型校验、描述生成及 API 测试证明原类型与物料可独立表达，非法状态组合被拒绝，PDF 渲染器没有新增对公开协议的依赖。

### I-AC02: 所有展示入口保留类型语义并一致降级

以组件测试及浏览器检查证明悬浮纸页、左上角 PDF 标识与底部信息条互不遮挡，普通图片和未知类型按设计展示；三类入口的图片加载失败均回类型图标且无失败文案，物料可用后恢复。横竖页及其他场景以设计验证矩阵为准。

### I-AC03: 一次性切换与现有行为可回归

以重建与缓存测试证明旧结构不会混读，刷新后的客户端正常消费新结构，原始内容不变且授权失效移除旧展示；无需跨版本兼容测试，`pnpm check`
通过。
