# Implementation

本文件是准备阶段的轻量初版；实施前按当时已合入的 PDF 代码细化，不表示已经修改或验证业务实现。

## Steps

### I-S01: 统一协议与兼容转换

依据[3 号设计](./ideal/03-Normalized-preview-design.md)调整共享契约、生成描述和所有 API 包装；保留状态及原类型信息，接入有界的旧协议转换和版本过渡，不重写调度或存储系统。

### I-S02: 接入共享展示与缓存

在共享渲染入口接入物料优先和类型封面降级，同步 Pin、Publication、节点详情、内存与 IndexedDB 校验和开发预览样例；与 PDF 实施分支对齐契约，不复制渲染器。

### I-S03: 验证兼容与失败路径

验证类型与物料组合、版本切换、未知类型、图片加载失败及授权失效；运行针对性测试和仓库 `pnpm check`，保留已有展示与内容安全行为。

## Acceptance criteria

### I-AC01: 协议可独立表达类型和物料

以契约、生成器及 API 测试证明 PDF 与视频样例可携带图片物料，空物料保留原类型，旧缩略图不会被误判为原始 WebP 文件。

### I-AC02: 所有展示入口一致降级

以组件测试和浏览器检查证明三类入口均物料优先、空物料显示图标，生成失败与图片加载失败仍可识别；文本、目录、长名称和暗色模式保持可用。

### I-AC03: 缓存升级与现有行为可回归

以旧描述、旧 IndexedDB 记录和公开 ETag 的兼容测试证明版本不会混读，旧 unsupported 能重新获取新物料，权限失效会移除旧展示；`pnpm check` 通过。
