# Deployment

本契约是可调整的现实验证初版；不包含 npm 发布、生产部署或新增服务端组件授权。

## Steps

### D-S01: 验证可交付的本地安装

在干净的临时目录验证构建产物的链接或包归档安装，记录前置条件、Kubo 兼容版本及用户可复现的入口；不发布 npm 包。

### D-S02: 验证真实账户工作流

在获准访问的现有环境中，使用用户提供的最小权限凭据完成上传、管理与撤销验证；无凭据或未获环境授权时明确报告阻塞，不修改生产部署。

## Acceptance criteria

### D-AC01: 用户能按文档启动

干净安装环境按文档完成配置、帮助查询和一次上传；保留不含凭据的版本、操作与结果证据，证明无需手写 CAR 导出和 HTTP 命令。

### D-AC02: 真实权限与公开语义一致

在授权环境记录真实账户上传、分页列表、详情、移除引用和 token 撤销结果；独立下载核对内容，并确认移除引用不等于擦除公开数据。测试夹具不能替代此项真实证据。
