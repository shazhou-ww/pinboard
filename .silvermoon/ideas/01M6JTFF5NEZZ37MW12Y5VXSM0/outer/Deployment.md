# Deployment

本契约是可调整的现实验证初版；不包含 npm 发布、生产部署或新增服务端组件授权。

当前交付核验与阻塞见
[交付证据](Delivery-evidence.md)。独立安装复用已核实的 0.2.0 归档；该版本没有包含已接受实现中的帮助修复，不把源码同步或 CI 成功当作 npm 已更新。真实账户操作须另行确认目标环境、公开测试内容和凭据安全输入方式。

## Steps

### D-S01: 验证可交付的本地安装

在未安装 Kubo、未运行 daemon 的干净环境验证构建产物的链接或包归档安装，记录 Node 前置条件及用户可复现的入口；不发布 npm 包。

复用已完成的准确 0.2.0 字节核验、Windows 独立归档安装与命令入口证据，不重复发包或全量测试。

### D-S02: 验证真实账户工作流

在获准访问的现有环境中，使用用户提供的最小权限凭据完成上传、管理与撤销验证；无凭据或未获环境授权时明确报告阻塞，不修改生产部署。

仅使用本次专用账户或用户明确指定的账户和短期 Agent token，所需 scope 为
`pins:read`、`pins:write`、`pins:delete`。不在聊天、命令参数、日志或证据中传递 token，不读取未知现有凭据，不伪造 session。使用明确可公开的合成文件，只管理本次创建的引用；如分页需要额外条目，先确认范围，不为凑页数批量写入生产。本地受限权限凭据保存是 D-AC01 明确要求的临时验证动作，需用户确认；验证结束移除专用本地记录，并由账户所有者在 Web 撤销专用 token 后验证拒绝结果。

## Acceptance criteria

### D-AC01: 用户能按文档启动

无 Kubo 的干净安装环境按文档完成配置、安全保存 token、帮助查询和文件、目录及 CAR 上传，并验证环境变量覆盖及本地 token 移除；检查凭据文件的实际权限且证据不含秘密。保留版本、操作与结果，证明无需另装 IPFS 工具或手写 HTTP 命令。

### D-AC02: 真实权限与公开语义一致

在授权环境记录真实账户上传、分页列表、详情、移除引用和 token 撤销结果；独立下载核对内容，并确认移除引用不等于擦除公开数据。测试夹具不能替代此项真实证据。
