# 用轻量 CLI 完成 Pinboard 上传与管理

## 问题

标准 Kubo 的远程 pin 命令只提交 CID，不能直接满足本服务的主动上传工作流；手写导出、认证和 HTTP 上传命令又过于繁琐。

## 结果

提供简短、可脚本化的 Pinboard
CLI：复用 Kubo 处理本地文件和目录，通过现有 API 上传完整 CAR、管理账户 pin，无需用户手动拼接多个工具。

## 边界

- 保持 Worker + R2、主动上传和完整 DAG 校验，不增加服务端 P2P、Kubo
  RPC 或标准远程 pin 服务承诺。
- 不重做 IPFS 底层能力，不改变用户已有 Kubo 仓库、配置或 daemon。
- 保持现有账户权限、显式公开确认和上传限制；本 idea 不授权 npm 发布或生产部署。

## 验收标准

- 文件、目录和已有 CAR 能通过短命令上传，取得与导出 DAG 一致的 CID。
- 用户能列出、查看及移除自己的 pin，自动化可获得稳定 JSON 与失败退出码。
- 不依赖服务端 P2P，不泄漏凭据，不污染本地 Kubo 状态；范围与风险见
  [CLI 设计](CLI-design.md)。
