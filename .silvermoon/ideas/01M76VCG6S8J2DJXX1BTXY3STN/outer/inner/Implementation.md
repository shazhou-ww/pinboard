# Implementation

## Steps

### I-S01: 实现实体范围与 CAR 变体

复用路径与 scope 遍历，增加准确整数范围解析和最小块选择，entity-bytes 优先隐含 entity；落实完全越界、部分交集和空实体规则。保持 CARv1/dfs/n，补齐协商优先级、响应参数、Content-Location 及范围 ETag，不扩展变体、整包快路径或单独性能优化。

### I-S02: 验证最小集合和协商边界

增加独立范围重建、实际读取计数、共享块顺序和错误输入测试；覆盖负偏移、跨块、超大偏移、非字节实体、HEAD/304、缺块与取消，同步准确支持范围和已知预检成本。

## Acceptance criteria

### I-AC01: 局部读取精确且可验证

用跨块、负偏移、越界、空实体及目录 fixture，独立检查返回 CID 集合、重建字节及实际读取集合，证明未先下载完整文件再过滤。删除或篡改所需块会失败，不以传输变小代替正确性。

### I-AC02: 协商与表示一致

逐项验证 query/header 优先级、质量及排除、响应参数、dfs/n、范围 ETag 和条件请求；dups=y、CARv2 等不支持变体明确失败，raw/图片/已有 scope 行为保持准确声明。

### I-AC03: 最终候选通过完整检查

未来实现的最终候选运行并通过 pnpm
check；候选变化后重新执行，不以生命周期检查或未执行的计划代替代码验证。
