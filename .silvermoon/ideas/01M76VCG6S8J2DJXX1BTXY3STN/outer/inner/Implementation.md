# Implementation

## Steps

### I-S01: 实现实体范围与 CAR 变体

增加范围选择和参数解析，复用路径与 scope 遍历；明确支持组合、拒绝规则及表示标识。

### I-S02: 验证最小集合和协商边界

增加独立范围重建、共享块顺序、重复块与错误输入测试，同步文档并运行 pnpm check。

## Acceptance criteria

### I-AC01: 局部读取精确且可验证

用跨块、负偏移、越界、空实体及目录 fixture，独立检查返回 CID 集合和重建字节，不以传输变小代替正确性。

### I-AC02: 协商与表示一致

逐项验证 query/header 优先级、响应参数、顺序、重复策略及条件请求；不支持的变体明确失败，pnpm check 通过。
