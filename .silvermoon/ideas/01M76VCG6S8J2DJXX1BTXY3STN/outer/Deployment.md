# Deployment

## Steps

### D-S01: 验证外部局部读取客户端

使用独立客户端读取已知多块文件的指定范围，记录返回 CAR 的块集合、参数及条件请求结果。

### D-S02: 按授权核验目标版本

本轮用户已重新明确授权旧工作流：实现子代理只准备并验证候选，父代理独立审查并批准全部门限，负责同步、生产 tag 发布及 Chrome
smoke。Chrome CDP 使用 `127.0.0.1:19302`；生产发布依照仓库 deployment
guide，从已在 origin/main 的提交创建正确 release tag。不得执行 schema
migration。该新授权仅更新本阶段种子，不改动历史 Ideal 方案文字或推定已经过门限。

父代理取得准确 revision 的必要门限后，核验生产边缘链路未改写协商、字节选择、Content-Location 与条件请求；独立外部 fixture、浏览器及版本证据由父代理补充。子代理不执行提交、推送、生命周期事件、发布或外部生产动作。

## Acceptance criteria

### D-AC01: 局部范围可外部复现

客户端重建字节与原文件切片完全一致；请求、版本、CID 集合及传输量证明没有退化为完整文件传输。

### D-AC02: 表示穿过实际 HTTP 链路仍准确

目标环境的响应参数、ETag、条件请求和错误变体结果有可复核证据，不混同本地与生产结论。
