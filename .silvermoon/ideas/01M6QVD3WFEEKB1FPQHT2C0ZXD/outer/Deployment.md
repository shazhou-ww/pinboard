# Deployment

用户已于 2026-11-06 明确授权发布。目标环境为 https://pinboard.shazhou.work，按
release
tag 流程发布已在 primary 的实现并验证，不执行数据库迁移。交付状态和准确的验证边界见
[交付状态](Delivery-status.md)。

## Steps

### D-S01: 核对版本并发布生产环境

确认已接受实现可从目标 primary 提交到达、CI 通过、生产队列没有其他活动发布；使用当天未占用索引的 annotated
release
tag，等待现有 Cloudflare 工作流完成，核对线上版本与健康状态。不得附带 SQL 迁移或其他未授权资源操作。

### D-S02: 执行线上冒烟并记录证据

使用获授权的测试账户或已有合成测试内容，验证 Pin 与 Publication 的名称和根描述过滤、排除字段、清空、无匹配、中文输入、窄屏，以及详情、公开读取和上传目标选择。优先只读；如需要新测试内容，仅创建可识别的非敏感夹具并记录清理范围，不更改用户既有内容。认证或浏览器不可用时如实记录缺失证明，不能以本地预览代替线上登录验证。

## Acceptance criteria

### D-AC01: 线上运行准确的目标版本

以 release tag、primary
commit、成功的部署工作流及线上响应/资产证据证明版本正确，首页和健康检查可用，且未执行数据库迁移。

### D-AC02: 登录态过滤与基本回归可验证

以线上认证 API 与真实浏览器操作记录证明名称/根描述命中、排除项不命中、清空及无匹配反馈、中文输入和窄屏可用，详情/公开读取/上传目标选择没有受到过滤影响。跨页完整性和竞争条件以实现阶段自动测试为主要证明，不在生产批量制造测试数据。未取得线上登录态或未完成手工验证时，本标准保持未完成，不能仅凭工作流成功通过部署 gate。
