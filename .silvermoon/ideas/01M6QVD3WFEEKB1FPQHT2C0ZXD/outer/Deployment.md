# Deployment

实现门禁已通过，代码与验证证据已同步到 primary。本阶段仍需目标环境的外部验证；自主处理门禁的授权不等同于创建 release
tag 或生产部署授权。实现无需数据库迁移，未执行生产操作。交付边界见
[交付状态](Delivery-status.md)。

## Steps

### D-S01: 验证可访问的预览环境

在可访问的预览环境准备跨页 Pin、Publication 和根描述测试数据，确认目标版本及可能的迁移状态，不使用真实用户私有内容。

### D-S02: 在明确授权后安排发布与复验

如需生产发布，按仓库部署指南单独取得授权；若实现包含 D1 迁移，另行取得生产迁移授权并核对回填次序。发布后复验首页过滤与既有公开访问，不以合并代码代表已经上线。

## Acceptance criteria

### D-AC01: 预览环境可证明实际过滤效果

以目标环境地址、版本及操作记录证明两个 item 类型的跨页名称/根描述命中、清空、无匹配、错误恢复及窄屏可用。

### D-AC02: 经授权的外部结果真实可用

在明确约定的目标环境核对版本及迁移完成证据，使用隔离测试账户复验过滤与分享/发布读取；若生产未获授权，明确保持未发布，不把预览结果当作生产验收。
