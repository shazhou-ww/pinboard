# 按名称和描述筛选首页 items

## 问题

Pin 和 Publication 增多后，用户需要快速缩小首页卡片范围，而不是进入全文搜索或逐页寻找。

## 结果

在顶部标题栏中央提供轻量关键词过滤框，覆盖当前账户全部有效 items，不限于已经加载的卡片。输入后原地筛选，清空后恢复普通浏览。

## 边界

- 普通 Pin 使用 name 和用户填写的根节点 description；Publication 使用 title 和当前发布版本的根节点描述快照。
- 整个输入去除首尾空白后，作为不区分大小写的字面子串；任一字段包含即可匹配。不拆词、不跨字段拼接。
- 不匹配 CID、子节点描述、旧版本、自动预览或正文；不引入全文搜索、相关性排序或高级查询语法。

## 验收标准

1. 桌面端输入框位于标题栏中央；窄屏不遮挡品牌或账户操作，键盘可用。
2. 名称或根描述中的关键词能找到未加载页的 item；仅在排除字段出现的关键词不会命中，账户隔离不变。
3. 输入、清空、无匹配、加载和失败状态明确；清空恢复普通列表，卡片查看、上传和发布操作保持可用。

交互提案见 [筛选交互](Filtering-UX.md)。
