# 筛选交互

## 已确认的产品语义

这是首页 items 的关键词过滤，不是站内搜索页。普通 Pin 与 Publication 都参与；两个字段为“或”，整个输入为一个字面子串。首尾空白忽略，内部空白保留；空输入等同于未过滤。大小写不敏感，不做拼音、繁简转换、模糊纠错或重音折叠。

普通 Pin 的描述只取当前账户对此根节点填写的文字。Publication 只取当前已发布版本的根节点描述快照，私有草稿的后续修改不影响它；发布新版本或回滚后按新的当前版本匹配。缺失描述视为无描述，不回退到自动预览。

## 布局提案

桌面端保持现有 64px 固定标题栏：品牌在左、过滤框相对视口真正居中、账户在右。不能只对两侧宽度不等的剩余空间居中。建议输入框宽 360px、上限 420px、高 40px，并给长账户名预留空间；空间不足时优先截断账户名，再切换窄屏布局，避免覆盖。

```text
| Pinboard       [ Filter items...          x ]       Account |
|                                                            |
|                         item wall                          |
```

窄屏采用两行顶部栏，不把输入框压成只能看几个字的小胶囊。第二行全宽过滤框，输入区和清空按钮触控目标至少 44px；同步调整正文顶部留白及滚动定位偏移。

```text
| Pinboard                                      Account |
| [ Filter items...                                  x ] |
|                       item wall                        |
```

仅登录后的管理首页出现输入框。公开分享页、Publication 阅读页、登录页不增加过滤框。

## 视觉选择

沿用现有 Instrument
Sans 和背景主题，不引入字体、强调色或新的工具栏。参考现有配色：主文字 #23332d、输入表面 #fffefa、雾蓝底 #e6edf3、淡紫底 #e8e3ef、焦点边线 #294d38；实际实现应复用届时现有主题 token，兼容其他 IDEA 对主题的更新。

输入框文字左对齐，使用页面正文级字号；容器居中不等于文字居中。保留卡片墙作为主角，过滤框只是安静的缩小范围工具。没有新增装饰渐变、搜索结果页或卡片入场动画。

自检后的取舍：不采用显眼的大搜索横幅，也不重设计整页；唯一的布局变化是顶部居中的轻量输入框，符合“关键词 filtering”的定位。

## 输入与反馈

- 使用现有英文界面语气：占位文字 `Filter items...`，独立可访问名称
  `Filter items by name or description`。不靠 placeholder 充当唯一标签。
- 不需要提交按钮。输入约 200ms 后更新；Enter 可立即应用。中文输入法 composition 期间不发出中间查询，确认后再过滤。
- 不自动抢焦点，不新增全局快捷键。非空时显示清空按钮，名称为
  `Clear filter`；点击后焦点回到输入框。输入框内 Escape 清空，不能干扰弹窗或账户菜单自己的 Escape 行为。
- 请求中保留输入焦点，结果区显示 `Filtering...`
  和忙碌状态。旧卡片可以保留，但必须标明正在更新，不能作为新关键词的已确认结果。无需把每次输入都变成全屏 loading。
- 无匹配时显示 `No items match this filter.` 和
  `Clear filter`；已有内容但未匹配，不展示“上传第一个 Pin”的新账户引导。
- 加载失败显示可重试的错误，不显示“无匹配”。异步结果状态使用温和的 live
  region，不逐键朗读整面卡片。
- 首版不显示全账户总结果数，避免把“已加载数量”冒充总数。存在后续匹配页时保留两个现有加载更多入口，各自只加载当前关键词的结果。
- 清空后立即退出过滤状态，恢复未过滤列表；允许回到默认首屏，不承诺恢复之前的滚动位置。关键词只保留在当前页面状态，不写入 URL、浏览器历史或长期存储。

## 操作期间的预期

详情弹窗、复制 CID、上传、拖放和发布仍使用原有操作。名称或描述更新、删除、恢复、发布或回滚成功后，以当前过滤条件重新取结果；不再匹配的卡片可以退出列表，但已经打开的详情不应被突然关闭。上传成功但被当前条件隐藏时，提示说明已成功并可清空过滤查看，不能看起来像上传失败。

首版不增加命中高亮或描述摘要；它们会扩张卡片的信息层级，且不是缩小范围所必需。
