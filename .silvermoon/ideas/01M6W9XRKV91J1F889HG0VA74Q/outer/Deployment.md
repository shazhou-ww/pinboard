# Deployment

## Steps

### D-S01: 在预览环境验证设置操作

实施验收后，在隔离预览环境通过真实浏览器核对设置及授权操作，仅使用专用测试数据。

### D-S02: 经授权后发布并抽验

生产发布须获得单独授权，遵循[部署指南](../../../../docs/deployment.md)的 tag 流程；未授权时停留在预览验证，不创建 release
tag。

## Acceptance criteria

### D-AC01: 预览环境行为正确

记录预览地址及浏览器证据，证明分类可达、浏览器偏好不影响其他设备，测试授权可撤销，测试回收站可进入及恢复。

### D-AC02: 授权发布后的入口可用

获得发布授权后，记录 release
tag 与发布地址，以桌面/窄屏抽验证明 Settings 打开、分类切换及关闭正常，未引入新的 API 或路由错误。
