# Settings 分类面板设计讨论

## 当前问题与设计方向

首轮分类面板已经上线。本轮针对用户体验反馈，只讨论更高的配色预览及更紧凑的授权管理布局，不改产品代码或发布新版本。上一轮实施与部署记录仅证明已上线版本，不是本轮方案的完成证据。

建议保留弹层而非新增全屏设置页：设置是从主画布进入的辅助操作，关闭后应回到原位置。通过一个更宽的双栏面板改善信息结构，而不是仅放大现有长列表。

## 信息架构

| 分类         | 内容归属                                       | 作用范围                                 |
| ------------ | ---------------------------------------------- | ---------------------------------------- |
| 通用（默认） | 三种背景配色、公开上传提醒、MCP 配置及授权说明 | 偏好仅当前浏览器，不同步；说明适用于账户 |
| 访问令牌     | token 创建/一次性密钥/有效或历史列表           | 当前账户                                 |
| OAuth 授权   | MCP 客户端授权表格、筛选、刷新、撤销           | 当前账户                                 |
| 最近删除     | 现有回收站入口、30 天恢复及公开副本说明        | 当前账户                                 |

按本轮反馈，将 token 与 OAuth 拆成两个独立一级页面，不再使用「Agent 与连接」父页或连接方式二级 tabs。两者的认证、生命周期、操作和表格各自管理；用 switch 加入仍可查询的无效记录。暂不增加没有对应功能的“账户”“安全”“高级”分类。

endpoint 和如何配置客户端集中在「通用」页，OAuth 页不再展示 endpoint 或连接说明按钮。两种授权页底部不放解释段落，名称可信性、一次性密钥和历史保留说明也集中到通用页；此整理不改变授权方式或数据保留语义。

## 授权记录列表

页面按授权方式命名为「访问令牌」与「OAuth 授权」，不按 agent、工具或脚本分类；它们都是可能使用授权的客户端。Token 名称只是标签，不证明持有者身份；OAuth 的客户端信息也不是可信认证标记。

两页都采用工具栏 + 表格 + 条目计数的紧凑结构，表格独立滚动，表头 sticky 固定。每行保留名称/客户端、权限、到期时间、状态与操作；一行是一条 token 或 OAuth 授权，不聚合客户端记录。长段介绍退为简短说明，避免挤占表格高度。

- 两页默认只显示有效授权，使用一个圆角 switch「显示无效授权」同时加入过期及已撤销记录；不使用下拉框或两个独立选项，与名称/权限搜索组合。无效行仍无撤销操作。switch 可通过点击标签或键盘 Space 切换，提供可访问名称与开关语义。
- 工具栏最左侧顶格是圆角搜索框，中间是无效授权 switch，最右侧是圆形 icon
  button：访问令牌用加号新建，OAuth 用刷新图标；两者带悬停提示与无障碍名称。窄屏搜索独占首行，筛选与操作在第二行。新建以独立小弹层展开，不挤压表格；OAuth 授权从客户端发起，不新增 Settings 内直接创建授权功能。
- 加载、空、失败在表格区域呈现，失败不能伪装成空列表。桌面所有列可见；窄屏采用表格区内部横向滚动，保留真正表格和列关系，页面不横向溢出。滚动区域可通过键盘聚焦。
- 已过期与已撤销筛选只展示服务端仍保留的记录，不改变 token 的 30 天历史清理规则，不承诺无限期保存 OAuth 历史。

## HTML 样稿

[打开表格样稿](./settings-table.mock.html)。旧版列表样稿已删除，避免入口混淆。纯 HTML/CSS/JS，离线可用，无外部依赖、API、真实凭据或持久化。样稿正文采用中文讨论标签，保留 token、OAuth 等术语；实施时沿用当前产品语言，以 Access
tokens 代替 Agent tokens，不把本构想当成全站本地化需求。

- 桌面：1040px 宽、720px 高，左栏 196px；固定 header 只显示 Settings，无副标题、无关闭按钮。授权页仅表格区域滚动，工具栏及条目计数不随行滚走。低高度窗口按视口收缩。
- 640px 以下：同一个面板，导航改为横向可滚动 tabs，详情在其下方；不把左栏压成无法辨认的图标。键盘方向与导航方向同步改变。
- 默认打开通用；配色色块加高至桌面 144px / 窄屏 108px，保留文字与单选标记。
- 使用[产品样式](../../../../../../apps/web/src/styles.css)中的 mist / sand /
  ice 同名主题变量和准确色值；选择配色同步预览背景、面板、导航、表格和按钮，而非仅改变背景。普通动作按钮采用圆角胶囊形，表格撤销操作采用圆形 glyph 图标按钮，含悬停提示及
  `aria-label`。
- 图标沿用[产品 Icon](../../../../../../apps/web/src/icon.tsx)的线性、currentColor 视觉语言；离线样稿用内联 SVG 表达撤销，不引入 Bootstrap
  Glyphicons 或外部图标字体。后续实施应复用产品 Icon 组件。
- 导航 Tab 高亮使用方角，搜索框使用圆角；保留普通动作的胶囊按钮和表格内圆形 glyph 按钮。
- 两页各有 24 条示例授权（16 有效、4 过期、4 撤销），用于实际体验固定表头与滚动；搜索、状态筛选、条目计数和空状态可交互。
- 所有数据明确标为示例；创建、撤销和刷新只显示演示提示，不声称调用成功。回收站只保留入口演示，本轮不模拟恢复或返回流程。
- 点击面板外侧或按 Escape 关闭；窄屏仍保留可点击的外侧间距。点击内部空白不关闭，从内部按下后拖到外侧释放也不关闭。

## 行为边界

1. **保存模型**：浏览器偏好仍逐项即时保存，无全局 Save 按钮；token 创建等账户操作仍有明确动作。保存失败必须显示错误，不可让开关误报成功。
2. **分类切换**：在单次打开过程中保留 token 草稿及已生成的一次性密钥，切换后显示未复制密钥提示和返回入口；只有显式 Dismiss 或既有关闭语义才清理。样稿不生成密钥，实施时需测试这一状态。
3. **请求及错误**：保留现有授权约束和忙碌时关闭限制；分类切换不应清除错误或隐藏正在处理的操作。OAuth 加载、空、失败状态须区分，不把“未加载”伪装成“没有授权”。
4. **回收站**：优先保留现有独立回收站视图，而非重复实现整张列表；打开时退出 Settings，返回 Settings 时定位最近删除。仍显示 30 天恢复、最后引用释放后的七天清理宽限及外部副本不可召回；没有永久删除按钮。
5. **无障碍与关闭**：使用有标签的 modal、tablist/tab/tabpanel；单个活动 tab 进入 Tab 顺序，方向键及 Home/End 切换。无关闭按钮，鼠标/触摸通过外侧点击关闭，键盘通过 Escape 关闭；两者都遵守忙碌时禁止关闭的规则。外侧关闭须同时在外侧按下和释放，避免拖动误关闭；焦点限制在弹层并在关闭时返回入口。配色不能仅靠颜色表达选择。

## 待讨论的取舍

- **默认分类**：通用集中偏好与配置说明，授权管理页专注工具栏和表格。
- **回收站深度**：建议本轮仅整理入口和返回路径；嵌入完整回收站会增加布局及状态管理范围，不作为第一版前提。
- **窄屏表格**：本版优先保留完整列，通过表格内部左右滚动查看；如操作列不够容易找到，讨论后可再考虑固定操作列，但尚未实施。

本文件和样稿用于讨论方向，不是已实施或已验证产品行为的声明；实施与发布方案仍可在对应阶段细化。
