# 用分类导航整理 Settings

## 问题

当前 Settings 把浏览器偏好、Agent
token、OAuth 授权和回收站纵向堆在一个小弹层中，用户难以定位操作，也难以区分设置的作用范围。

## 结果

保留一个 Settings 面板，以「浏览器偏好 / Agent tokens /
OAuth 授权 / 最近删除」四个一级分类和独立详情视图呈现内容；桌面左右分栏，窄屏仍能轻松切换。

## 边界

- 只重组现有能力，不新增账户设置、永久删除或跨设备偏好同步；顶部仅 Settings，无关闭按钮，外侧点击或 Escape 关闭，忙碌时禁止关闭。
- 保留 token 与 OAuth 的权限、有效期、撤销及一次性密钥展示语义；保持 30 天恢复和公开内容告知。
- 本轮是构想讨论，HTML 为独立设计样稿，不接入 API，也不修改产品页面。

## 验收标准

- 所有现有 Settings 内容都有清晰归属，浏览器偏好与账户授权不混淆，token 与 OAuth 在两个独立一级页面管理。
- [交互样稿](./settings-panel.mock.html)能展示四个一级分类切换、token 有效/历史列表、简洁标题及外侧点击关闭，兼容桌面/窄屏。
- [设计说明](./Design.md)明确交互边界、关键状态及待讨论取舍，足以决定是否进入实施。
