配置 MCP

在支持 MCP 的客户端添加以下远程地址，然后从客户端发起 OAuth 连接，并在 Pinboard 确认授权。

MCP endpoint https://pinboard.example/mcp · 示例地址

也可以使用访问令牌连接支持该方式的客户端。令牌名称只是标签；客户端名称不证明可信。密钥仅创建后展示一次，不出现在授权表格。

访问令牌历史按既有 30 天保留规则清理。过期或撤销的授权可在相应页勾选筛选项查看；过期授权不需再次撤销。
