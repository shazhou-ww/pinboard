# Implementation

## Steps

### I-S01: 拆分分类详情

构想验收后按[设计说明](./ideal/Design.md)拆分现有 Settings 内容，沿用组件与样式体系，不改变普通详情弹层。

### I-S02: 保留操作状态与无障碍交互

接回现有偏好、token、OAuth 和回收站操作，明确类别切换、一次性密钥、错误及忙碌状态；支持窄屏和键盘导航。

### I-S03: 验证行为兼容

补充针对性 UI 测试并运行项目检查，以浏览器核对桌面、窄屏及焦点行为。

## Acceptance criteria

### I-AC01: 内容与操作无遗漏

以 UI 测试及现有行为对照证明：偏好仅存本浏览器，token 和 OAuth 独立，恢复及公开内容说明仍可访问。

### I-AC02: 切换不丢失重要状态

用组件测试证明表单草稿、一次性密钥提示、错误及忙碌限制在切换时保持预期；键盘可切换分类并正常关闭弹层。

### I-AC03: 布局与检查通过

以桌面及 390px 窄屏浏览器验证无横向页面溢出、内容与关闭按钮可达，并以
`pnpm check` 通过作为仓库质量证据。
