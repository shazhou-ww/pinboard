# Implementation

## Steps

### I-S01: 定义权限与兼容规则

明确逐项归属、合法引用、完整内容树、失败写入、删除恢复和共享字节的读取边界；确定存量策略与所需迁移，保留凭证和权限范围限制。

### I-S02: 贯通服务端与客户端交互

覆盖所有内容、元数据及引用入口的授权和缓存行为；按 [UX 说明](ideal/UX.md) 调整 Web，同步 CLI、MCP、共享契约与直接相关文档。

### I-S03: 验证隔离与视觉一致性

补齐跨账号、匿名、受限凭证、共享 CID、历史和缓存测试；在真实 Web 验证桌面与移动布局，执行针对性检查及 `pnpm check`。

## Acceptance criteria

### I-AC01: 无读取与引用旁路

通过授权矩阵及失败写入测试证明私有 DAG、块、预览、描述、历史、HEAD／304 和下载不可越权读取，凭 CID Pin、单块补齐及 Publication 引用不能自行获取权限。

### I-AC02: 交互满足细化要求

通过组件测试和浏览器测量证明私有锁位于 info bar 最前面且不改变 preview 间距或栏高；当前版本号替换卡片图标，详情移除类型 icon 并在标题同一行最左侧提供可点击权限图标；上传和更新不直接修改权限。

### I-AC03: 状态与兼容行为可靠

通过共享引用、公开转私有、保存失败、版本更新回滚及恢复测试证明权限一致、失败保留原状态、存量按已定策略迁移，客户端凭证边界不变；完整检查通过。
