# 逐项访问权限的 UX 交互说明

本文支持 [构想契约](Idea.md)，记录本轮细化的用户交互要求。
[可交互 Mockup](pinboard-access-ux.html) 是从本次讨论复制的独立快照：
左侧复刻现状，右侧展示提案；可在浏览器直接打开，不依赖外部资源。
Mockup 的示例账号、内容、登录、下载和保存均为演示，不是正式功能或生产验证证据。

## 权限规则

- 固定 Pin 与 Publication 各自管理公开／私有。新建统一默认私有。
- 私有项仅所属账号及其明确授权的 Agent 可读取；管理仍要求相应权限范围，读取授权不自动允许修改。
- 公开项允许任何获得链接的人读取与下载，不允许他们修改内容或权限。
- Publication 的设置覆盖标题、描述、预览、当前版本和全部历史版本；不做逐版本权限。
- 知道 CID、复制链接或创建引用不授予私有访问权限。同字节存在其他公开引用时，私有记录的元数据仍隔离，但字节不承诺保密。

## 内容墙

- 仅私有项显示锁，位置是底部卡片 info bar 的最前面，即名称之前。
- 锁只读，提供「私有」悬停说明和可访问名称；公开项不添加权限标记。
- 不在 preview 顶部加权限标签，不为锁增加 preview 留白，也不增高 info bar。
- Publication 右上角原位以 `vN` 替换现有叠层图标。`N` 是当前版本，不是历史总数；更新后显示新版本，回滚后显示目标版本。
- 固定 Pin 不显示版本标记。版本号只读；卡片仍打开 detail view，不增加权限快捷切换或独立跳转。
- 保留内容搜索，可按全部、私有和公开筛选；筛选不修改权限。

## Detail view

- 去掉标题栏原有的文件类型 icon。
- 将权限图标放在标题同一行的最左侧：私有显示锁，公开显示地球。
- 作者点击该图标打开「访问与分享」，并有明确的悬停提示、按钮名称和键盘焦点。
- 非作者的权限图标只读，不能进入权限编辑；保留版本标记、内容阅读、CID 复制及原文件／ZIP／CAR 下载。
- Web 的所有公开／私有修改都在 detail view 发起，确认面板也从此处打开。侧栏「访问与分享」可作为同一详情中的入口，不产生第二套设置。

## 上传、更新与转换

- 上传表单只读说明新内容默认私有，不提供公开／私有选择器；上传完成进入详情，再决定是否公开。
- 创建 Publication 不等于公开；上传同时创建的 Pin 与 Publication 均默认私有，随后各自在详情管理。
- 向已有 Publication 更新内容，沿用目标的权限，不改变它或源 Pin 的设置。
- 更新页只有只读访问状态；需要调整时先返回详情，不能直接从更新表单打开权限编辑。
- 私有 Pin 被引用到公开 Publication 前，明确确认文件字节及随版本发布的描述会公开，源 Pin 的设置仍私有。
- Pin 转换为 Publication 沿用源项设置，不意外公开；版本更新和回滚也不改变整项权限。

## 分享与切换确认

- 私有项提供「本人访问链接」，明确复制不会授予他人权限，也不会改变私有状态。
- 公开项提供跟随链接和固定版本链接，固定版本链接标注对应版本。
- 「设为公开」是单独的明确操作，确认范围包含 Publication 全部历史；本次确认下载与缓存不可收回的风险，不提供永久跳过。
- 「设为私有」说明将停止此项的新匿名读取，但既有下载、浏览器缓存及外部副本无法收回。
- 相同内容仍有其他公开引用时，额外说明字节仍可被匿名读取；不暴露其他账号的私有记录或身份。
- 取消确认不改变状态；保存成功后再更新图标与提示。保存失败保留原权限，明确报错并允许重试。

## 访客与恢复

- 公开分享页保留匿名读取与下载体验。
- 受保护链接对未登录访客提示登录以检查权限，不确认内容存在；登录也不保证授权。
- 其他账号看通用不可访问页面，不展示标题、CID、缩略图、描述或版本数量；可切换账号，不增加尚未支持的「申请访问」入口。
- 作者可正常读取自己的私有项；需要修改权限时进入 detail view。
- 回收站显示原访问状态；恢复沿用原设置，公开项恢复前说明会重新开放链接及历史，不增加权限切换入口。
- CLI／MCP 明确输出访问状态，私有读取使用授权凭证；不能建议用户为了下载而公开内容。

## 尚需实施前明确

存量公开项如何迁移尚未定案。当前建议保留它们的公开状态，
避免未经作者操作改变原分享行为，并告知过去公开的副本无法收回。
第一版不增加指定用户共享、密码或限时链接、逐版本权限及原创作者身份验证。
