# Deployment

## Steps

### D-S01: 确认上线与数据迁移前提

按仓库部署指南确认存量策略、回退风险及旧公开缓存处理，取得独立的生产发布与 D1 迁移授权；构想验收不授权部署。

### D-S02: 执行授权发布与缓存处理

获准后分别执行必要迁移、标签驱动发布和可控 CDN 清理，告知已有浏览器缓存及外部副本无法收回。

### D-S03: 验收真实访问与交互

在获准环境以两个账号、匿名请求和受限 Agent 验证私有下载、公开分享、共享内容和历史；确认最终界面并留存可复核证据。

## Acceptance criteria

### D-AC01: 上线与存量策略有据

部署、数据迁移和缓存操作有明确授权及可核对记录，存量内容符合已定策略；通过部署记录和抽样访问证明。

### D-AC02: 私有授权与公开切换有效

真实请求证明作者可读取，匿名、其他账号和低权限凭证不可访问私有内容及历史；取消最后公开引用后无服务端或可控 CDN 匿名命中。

### D-AC03: 正式界面符合访问预期

正式 Web 的桌面及移动验证证明锁和版本位置正确、权限仅在详情管理、访客不泄露私有元数据；Web、CLI 和 MCP 的公开／私有访问结果一致。
