# Deployment

## Steps

### D-S01: 验证独立 CAR 客户端

使用不依赖服务端遍历逻辑的客户端，从标准 URL 获取多级路径证明并校验；记录拒绝未支持范围的结果。

### D-S02: 按授权核验目标环境

用户已明确授权本迭代生产发布及 Chrome for
Testing 冒烟验证；父任务按部署指南执行，本实现子任务不创建标签、不部署、不接受阶段门。无需数据库模式迁移。在发布版本核验权限、标准路径证明、已有 raw/图片/完整 CAR 接口，并记录 Chrome 会话及独立离线 Kubo 验证。

## Acceptance criteria

### D-AC01: 外部证明可独立消费

保留请求、客户端版本、CAR 校验及篡改失败证据，不以响应 200 或能解析 CAR 代替证明验证。

### D-AC02: 目标环境不扩大权限

私有内容拒绝、公开内容成功、断连与旧接口回归有环境标识和可复核结果，Chrome for
Testing 冒烟与独立离线 Kubo 校验有明确版本与证据；未发布环境明确标为未验证。
