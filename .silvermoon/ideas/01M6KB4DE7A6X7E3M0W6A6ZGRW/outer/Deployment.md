# 落地初版

## Steps

### D-S01: 验证迁移与定时清理

在经授权的非生产环境验证迁移、存量数据宽限期初始化和定时清理；以受控测试数据验证保留边界与日志，不通过等待真实保留期完成测试。实现已引入
`0003_retention.sql`
及每小时 Cron；迁移与切换期间须停止旧 writer，禁止以旧版 writer 回滚，并验证回填、对象声明及实际运行预算。

### D-S02: 验证用户流程与发布条件

验证 unpin 列表移除、共享内容读取及 token 有效与历史列表；确认备份、监测与暂停清理的操作方式。生产部署须单独明确授权，不启用默认 push 部署。

## Acceptance criteria

### D-AC01: 外部清理行为可验证

非生产环境证据表明定时任务可运行、无引用内容和失效 token 按约定回收，存量及共享数据受到保护；失败可定位并安全重试。

### D-AC02: 用户流程和运维准备完成

非生产冒烟验证列表及权限行为正确，运维具备监测与停止回收的明确方式；未经授权不部署生产。
