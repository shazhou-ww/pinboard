# 回收无引用内容并清理失效 token

## 问题

Unpin 仅移除账号引用，内容与索引长期积累；已撤销或过期的 token 记录也永久保留，混在有效列表中。

## 结果

用户取消固定后，内容立即从自己的列表消失；服务端自动回收无引用内容。失效 token 保留有限历史，默认界面只显示有效 token。

## 边界

- 内容从不再被任何账号的有效 pin 或其 DAG 引用起保留 7 天；其他用户及共享 block 不受影响。
- 不提供回收站、恢复 pin 或“彻底删除”入口；不承诺删除 CDN、其他节点或已下载副本。
- Token 撤销或过期立即不可用；管理记录保留 30 天，不扩展为 API 调用审计系统。

## 验收标准

- Unpin 成功后立即移出列表；无引用满 7 天的内容最终被回收，仍被引用或重新 pin 的内容保持可用。
- Token 默认列表只展示有效项，历史可查看；从撤销与过期较早发生的时间起满 30 天后自动清理记录。
- 自动清理涵盖孤儿内容及相关索引，失败可观测且可安全重试，不误删共享数据。
