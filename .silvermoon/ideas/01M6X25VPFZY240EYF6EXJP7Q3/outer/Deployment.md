# Deployment

这是准备阶段的外部验证初版，部署时再细化；构想验收不包含本契约。创建本 idea 不授权生产发布。

## Steps

### D-S01: 确认发布授权与候选

在获得明确生产发布授权后，按 [部署指南](../../../../docs/deployment.md) 确认已在
`origin/main` 的候选与发布前提；不自行部署或执行 D1 迁移。

### D-S02: 验证发布后的真实详情

在已授权发布完成后，用受控样本检查生产环境的两类详情、历史版本、分享与下载，以及桌面和窄屏体验，保留可复查的外部证据。

## Acceptance criteria

### D-AC01: 发布来源与授权可追溯

通过发布授权、`origin/main` 候选和 tag-driven
workflow 结果证明生产运行的是已验收实现；没有未经授权的生产部署或 schema 操作。

### D-AC02: 真实使用结果符合设计

通过生产浏览器与链接、下载结果证明：阅读优先层级可用，普通 Pin 与 Publication 的信息和管理差异清楚，历史浏览不改变 current，现有公开检索路径仍正常。
