# Implementation

实施遵循已验收的 [A 设计](./ideal/Design.md)。本契约与 [验证证据](./Evidence.md)
定义主体世界验收范围；生产发布另由现实世界契约约束。

## Steps

### I-S01: 整理阅读骨架与内容展示

按 [设计说明](./ideal/Design.md)
调整普通 Pin 与 Publication 的身份、预览、说明和事实区域，复用现有安全预览能力。桌面使用宽详情容器与内容/辅助栏，390px、320px 使用单列；长名称和 CID 不横向溢出，关闭与主动作滚动后仍可访问。说明默认只读，根内容保持不受高级节点查询影响。

### I-S02: 整理操作与版本上下文

Share/Download 常驻；More 分离改名、关联、转换、转换后上传、发布与最近删除。说明显式编辑，取消恢复原文；写入期间禁止关闭，未保存关闭与刷新需确认。高级节点查询折叠但保留授权根约束。Publication 默认查看 current，选中 revision 仅切换阅读内容/说明/事实；跟随链接保持稳定身份，固定链接和下载绑定选中版本 CID。Make
current 独立确认并保留 sequence CAS；发布任务使用真实 publication 状态与 owned
Pin 选择。

### I-S03: 验证交互与既有行为

补齐组件与 Chromium 行为测试，覆盖回滚、失败/重试、迟到响应、空说明与有限预览能力。运行
`pnpm check`
与独立本机浏览器检查，保存合成数据证据，更新直接相关文档。服务端路由、授权、存储、公共页面及迁移不改动。

## Acceptance criteria

### I-AC01: 阅读层级与响应式一致

通过组件测试与 1440px、390px、320px
Chromium 证据证明：打开即可识别内容与主操作，默认无编辑/节点查询表单；长名称/长 CID 不溢出，空说明可识别。图片、PDF、文本、目录与 pending/failed/unsupported 的提示不宣称新增阅读器或导航能力。

### I-AC02: 操作和版本语义保持正确

通过行为测试证明：current v3
/ 五版本与单版本状态正确，浏览 v5 不修改 current；分享与下载固定到选中版本，显式回滚使用 expectedSequence 且不创建 revision。说明冲突保留草稿，发布失败保留 owned
Pin 和选择，历史/说明失败可重试，迟到响应不能覆盖新版本。关联保留 Pin、转换替换身份，以及上传后发布失败/转换部分成功/最近删除恢复由已有 Worker/CLI 回归测试证明；界面保留原有公开告知与独立确认。

### I-AC03: 可访问性和仓库检查通过

通过真实浏览器键盘、菜单 Escape、弹窗焦点约束、卡片焦点返回及窄屏检查证明操作可用。直接相关文档更新，`pnpm check`
通过；公共路由、服务端授权与预览资源校验无削弱。本地合成数据检查不替代部署后真实认证验收。
