# Implementation

这是准备阶段的轻量初版，实施时再细化；构想验收不包含本契约。

## Steps

### I-S01: 整理阅读骨架与内容展示

按 [设计说明](./ideal/Design.md)
调整普通 Pin 与 Publication 的身份、预览、说明和事实区域，复用现有安全预览能力并适配窄屏。

### I-S02: 整理操作与版本上下文

保持分享和下载易于访问，将编辑、发布及高级查询放入明确入口；区分选中 revision 与 current，保留独立的管理确认和失败恢复路径。

### I-S03: 验证交互与既有行为

补齐相关组件与行为测试，检查两类卡片、预览状态、回滚场景、授权与键盘操作，更新直接相关文档并运行仓库检查。

## Acceptance criteria

### I-AC01: 阅读层级与响应式一致

通过组件测试和桌面、窄屏浏览器检查证明：打开详情即可识别内容、说明和主操作，长名称及空说明不破坏布局，现有预览类型与失败状态仍可理解。

### I-AC02: 操作和版本语义保持正确

通过行为测试证明：分享和下载绑定明确的内容版本，浏览历史不修改 current；私人说明、公开快照、转换与关联的区别以及写入失败和冲突处理保持正确。

### I-AC03: 可访问性和仓库检查通过

通过键盘与焦点检查证明关闭、编辑及确认流程可用；直接相关文档更新，`pnpm check`
通过，公共路由和服务端授权未被削弱。
