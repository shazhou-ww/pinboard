# 以阅读优先的详情视图呈现共享内容

## 问题

卡片详情把内容预览、节点查询、描述编辑和发布管理堆在同一层，查看内容与常用操作缺少清晰路径。

## 结果

采用 A「阅读优先」方向，让内容成为主角，说明与事实易于查阅，分享和下载易于操作。普通 Pin 与 Publication 共享信息骨架，同时清楚表达固定内容与版本化身份的差异。

## 边界

- 范围是卡片详情及其关联任务入口；公共页面重构、新预览能力和存储变化不在本次范围。
- 保留私人元数据、公开版本快照、服务端授权及现有发布、回滚、恢复语义。
- 设计细节、交互边界与两类卡片的 A 方案 Mock 以 [Design.md](./Design.md)
  为依据；不实施 B/C 方向。

## 验收标准

- 打开任一类卡片先看内容与身份，常用操作清晰，编辑和高级查询不再抢占默认阅读路径。
- 普通 Pin 显示固定内容与私人说明；Publication 显示选中版本的内容和快照，并明确区分正在查看、current 与最新版本。
- 桌面与窄屏均能方便阅读和操作；版本浏览不改变 current，分享、下载及管理行为不发生语义退化。
