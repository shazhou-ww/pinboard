## 共享逻辑：身份、内容、说明、操作

两类详情共享「身份 → 内容 → 描述与事实 → 分享/下载 → 专属管理」的阅读路径，不强求相同尺寸、相同字段或完全相同的布局。

| 区域     | 普通 Pin                          | Publication                                              |
| -------- | --------------------------------- | -------------------------------------------------------- |
| 身份标题 | 私人名称、固定内容身份            | 公开标题、稳定身份、current 与版本数                     |
| 内容区域 | 根内容的预览与事实                | 正在查看的 revision 的预览与事实                         |
| 说明     | 所有者的私人、root-scoped 说明    | 选中 revision 的公开只读说明快照                         |
| 分享     | 固定内容链接与 CID                | 跟随 current 链接、固定版本链接与选中 CID                |
| 下载     | 固定 CID 的原文件或 ZIP、完整 CAR | 固定选中 revision 的原文件或 ZIP、该 revision 的 CAR     |
| 专属管理 | 改名、关联、转换、最近删除        | 发布新版本、浏览历史、显式设为 current、最近删除         |
| 高级信息 | 完整 CID、blocks、可达节点查询    | 选中 CID、blocks、Publication ID、Sequence、只读节点查询 |

主阅读区不再先显示 Node CID 输入框和 Read
node。元数据查询保留在高级入口，而不是被删除。默认显示说明文本，只有明确进入编辑时才显示输入框及保存、取消。

## 桌面与窄屏

桌面采用较宽的详情容器：内容在左，辅助栏在右；普通 Pin 的辅助栏以说明、类型、大小和添加时间为主，Publication 的辅助栏突出说明快照和版本列表。标题附近显示类型、大小与内容身份，让卡片到详情保持视觉连续性。

窄屏切为单列，辅助信息位于预览之后；分享和下载保持易于访问，其余管理任务可从 More 进入。长名称允许换行，长 CID 不撑破容器。阅读主区域不被固定表单挤压，也不能因版本较多而失去关闭或常用操作入口。

关闭规则沿用现有正常阅读行为，保留明确关闭按钮与 Escape；写入期间不能误关闭，关闭后取消过期读取并返回触发卡片的焦点。编辑中关闭需明确处理未保存内容。弹窗焦点约束、菜单焦点返回和触屏入口都要保留，不依赖 hover。

## 操作层级

常驻主动作是 Share 与 Download。分享菜单明确说明链接是否会随 current 改变；下载菜单默认原文件或目录 ZIP，CAR 是次级导出选项。打开公共页面作为次级入口。

| 操作                   | 所属位置与语义                                                             |
| ---------------------- | -------------------------------------------------------------------------- |
| 编辑 Pin 说明          | 说明旁的显式 Edit；保存私人说明，不修改既有发布快照或 CAR                  |
| Rename Pin             | 轻量管理入口；仅修改私人名称，CID 不变                                     |
| Add to a publication   | More 中的独立任务；选择已有 publication 或显式公开标题创建，保留源 Pin     |
| Convert to publication | More 中的独立确认；替换 Pin 身份，原内容成为 v1，不在 trash 留一个重复 Pin |
| Convert & upload       | 合并为任务入口，再选择文件或目录；转换后的原内容是 v1，上传内容是 v2       |
| Publish new version    | Publication 的明确管理入口；独立任务中选择文件、目录或已有 owned Pin       |
| Make current           | 历史上下文中的显式动作，另行确认；不与单纯选择版本混淆                     |
| 移到最近删除           | More 中的危险动作，独立确认；保留 30 天恢复及不能召回公开字节的说明        |

Publication 选择 owned
Pin 时应优先让用户识别名称与内容，而不是把原始 CID 输入框作为默认发布表单。文件或目录仍要经过选择、审阅和上传确认，不能因入口变得简洁而省略授权与公开内容告知。

不新增 Publication 改名等当前未有的管理能力。不把多个 publication 因 CID 相同而合并；每个稳定身份、标题、current 和历史仍独立。

## Publication 的两个上下文

身份上下文是 publication 及其 current；阅读上下文是选中 revision。打开详情默认查看 current，不假定最大 revision 就是 current。

例如 current 为 v3、总计五个版本时：

1. 选择 v5 仅浏览历史，不调用回滚；内容、说明快照、大小、日期和 CID 切到 v5。
2. 界面同时说明「正在查看 v5」和「公开跟随链接仍指向 v3」。
3. Share 中跟随链接仍指向稳定身份；固定版本链接和 CID 指向 v5。
4. Download 读取 v5 的确定内容，不能在请求执行时随 current 漂移。
5. Make current 是单独确认的写操作；v1 至 v5 保留，不产生新 revision。
6. 发布新版本针对 publication 的真实状态，不把正在查看的历史版本误当作写入基线。Sequence 留在技术信息中，但冲突保护不能被移除。

既有不可变快照语义保持不变：重新发布同一 current
CID 是 NOP，不会应用私人说明的改动。浏览旧版本不能直接编辑其公开说明。

## 预览能力与权限边界

- 图片展示现有缩略图，清楚提示完整内容可下载；不暗示已提供原图查看器。
- PDF 只展示已有第一页材料，不新增完整阅读器、脚本执行或外部资源加载。
- 文本是有限摘录；目录是已有目录预览，不伪装成可用的路径浏览器。
- 路径到 CID 的导航解析需要额外能力，本次不扩大范围。
- 未支持预览的内容显示类型与下载入口；生成中或失败状态明确呈现并允许适当重试，不能用空白或成功状默认值掩盖错误。
- Pin 名称和私人说明不能泄露给公开访客；Publication 标题、历史和版本说明快照按既有规则公开。展示层隐藏按钮不能替代服务端授权。
- 高级节点查询仍限定在授权根或选中 revision 的可达子节点，不允许任意 CID 查询绕过现有访问约束。

## 错误、恢复与需要证明的状态

详情读取、说明读取和历史读取失败在相应区域明确显示错误与重试，不阻止用户识别已有可用内容。迟到响应不能覆盖已切换的 Pin、Publication 或 revision。

说明编辑保留并发保护；冲突时保留用户输入并要求刷新或明确处理，不静默覆盖。上传成功但发布失败必须说明已保留的 Pin；转换成功但后续上传或发布失败必须说明已产生的 publication 与 v1，不能宣称整个任务完成或悄悄撤销部分成功。

删除 Pin 不影响独立 publication 引用；删除 publication 会关闭其公共链接与历史，独立 Pin 不变。两者都有 30 天恢复窗口；不提供永久删除，也不宣称可以擦除缓存、下载副本或仍被引用的公开字节。

实现后需证明以下设计状态，而不只检查一个正常图片示例：

- 普通 Pin 与单版本、多版本 Publication，包括 current v3 / 五个版本的回滚场景。
- 空说明、长名称、长 CID；图片、PDF、文本、目录与无预览材料。
- 预览 pending、failed、unsupported，历史读取失败、重试和切换后迟到响应。
- 所有者可管理，未授权访问被服务器拒绝，公开展示不包含 Pin 私人元数据。
- 分享类型、固定版本下载、浏览历史、回滚确认、关联与转换，以及编辑取消。
- 写入冲突、上传后发布失败、转换后部分成功、最近删除与恢复语义。
- 桌面、窄屏、触屏和键盘；关闭、焦点返回、任务确认与未保存编辑处理。
