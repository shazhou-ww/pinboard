## 可读性与磨砂层

自动化计算直接读取产品 CSS 的实际值，而不是样稿。采用 WCAG 的 sRGB 相对亮度比值，按未舍入值与阈值比较；下表仅为方便阅读而保留两位小数。

| 最小组合                           | 晨光雾屿 | 玫瑰沙丘 | 晴空冰海 | 阈值 |
| ---------------------------------- | -------- | -------- | -------- | ---- |
| 正文／所有受测实色承载面           | 9.50     | 8.95     | 9.09     | 4.5  |
| 次要文字／所有受测实色承载面       | 5.03     | 4.90     | 4.76     | 4.5  |
| 强调文字／面板及轻量交互底         | 4.93     | 4.97     | 4.74     | 4.5  |
| 白字／主操作三个状态               | 6.53     | 6.95     | 6.42     | 4.5  |
| 必要输入边界／面板                 | 3.69     | 3.75     | 3.56     | 3    |
| 焦点／所有受测实色承载面           | 4.72     | 4.97     | 4.68     | 3    |
| 画布说明文字／完全不透明的最深线稿 | 4.87     | 4.74     | 4.57     | 4.5  |
| 次要文字／90% 磨砂层覆盖纯黑       | 5.37     | 5.27     | 4.98     | 4.5  |
| 次要文字／94% 磨砂层覆盖纯黑       | 5.89     | 5.78     | 5.47     | 4.5  |

实色承载面包含面板、轻量底、悬停底、选中底及四个背景端点。渐变的 sRGB 通道由端点约束；测试另读取既有 SVG 的所有渐变色阶，即使线稿完全不透明，画布正文／说明文字仍至少 4.5，强调色的大字与必要图标／焦点仍至少 3。背景线稿本身为无交互的低对比装饰，不将每一条装饰线误称为必要控件边界。固定语义配对的正文对比度分别为成功 6.68、警告 6.48、错误 5.95。

现有 45%／72% 信息层和约 62% 顶部栏不能保证叠在任意深色图片或文字上时的可读性。因此图片信息层、菜单、顶部栏、浮动反馈、发布徽标及拖放层采用 94% 的同调面板色；文本／代码／目录信息层采用较轻的 90%，仍保留原有模糊半径和底下内容的柔化轮廓。没有改为全不透明平板，也没有把主题颜色施加到原图上。

测试检查两种实际不透明度在纯黑、纯白底上的合成：所有 sRGB 通道均被这两个极值约束，且最深合成背景仍亮于所测正文、次要文字及强调色，故普通 SDR 内容的最坏对比度有下限。此证明不依赖模糊能消除图片细节，仍不替代浏览器的文字抗锯齿、色彩管理、HDR、强制颜色模式或整站无障碍审查。图片卡片的内侧焦点环新增同调实色隔离带，避免焦点直接落在任意图片像素上；结构与卡片大小不变。
