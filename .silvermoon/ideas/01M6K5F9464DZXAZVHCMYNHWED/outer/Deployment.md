# Deployment

## Steps

### D-S01: 确认验证环境与回退边界

在得到明确环境授权后安排发布与远端验证，确认现有内容保留、索引兼容和回退条件；保持默认关闭推送部署，不擅自发布生产环境。

实现验收后先由单独授权的 D1 操作者核查生产现有 schema 和迁移记录，再仅补充
`0002_car_storage.sql` 的 CAR 表及索引；已手工初始化的旧库不可盲目重放
`0001`。沿用 release
tag 工作流，不把迁移或权限扩展加入发布流水线。新数据写入后旧 Worker 无法读取 CAR-only 内容，回退须保留 CAR 读取能力，以前向修复为默认；不得为回退永久双写全部独立块。具体操作见
`docs/deployment.md` 的 CAR rollout prerequisite。

### D-S02: 验证真实 R2 下载与性能

在获授权环境对相同多小文件样本和多块大文件进行单块、整包及旧内容下载验证；在相同条件下重复测量改造前后首字节时间、总耗时、对象请求数及存储字节数，并注明缓存状态和样本规模。

## 授权环境与可复现实测协议

用户已明确授权本次生产发布、必要的增量 D1 迁移与真实 smoke；这不构成 outer 验收。目标为
`https://pinboard.shazhou.work`、Worker `pinboard`、account
`92c3c4fdcc84a1590555bccf4f111de2`、D1 `625b568d-106b-4fe1-af33-3eac4fe0a354`
和私有 R2 `pinboard-blocks`。仅在隔离分支 `delivery/car-indexed-storage`
工作，不修改已验收的 inner/ideal 或源代码。

前置条件：确认控制面身份及 D1 查询/写入权限、既有 release 工作流所需部署凭证，并通过现有应用会话或有效 Agent
token 取得真实上传权限。凭证仅在受保护环境使用，不写入证据、日志或 Git；不得伪造会话、扩大永久 token 权限或部署测试后门。先读取 sqlite_master、PRAGMA 和迁移记录，再只补充缺失的
`0002` 表/索引；不重放
`0001`，不改动旧数据。任一前置条件无法安全满足即记录明确阻塞，不创建发布 tag。

同一组确定性公开合成夹具在切换前后使用：至少 128 个小文件（含空文件、嵌套目录），以及至少 8
MiB 的多区块文件。保留文件清单、字节数、SHA-256、Kubo 参数、根 CID 与 CAR 字节数。尽可能在旧 Worker 上先上传并测量；切换后分别测量旧对象兼容读取和新 CAR-only 上传（内容可去重，须记录实际存储命中）。若需不同根以触发新存储，预先固定两组等规模夹具，且前后均测量同一组；不得将不同规模结果宣称同条件比较。

每组 raw、标准整包 CAR 及现有整包导出接口均记录 HTTP 状态、首字节与总耗时、响应字节数、时间戳、请求路径、ETag 与缓存相关响应头。首次 cache-busted 请求标为“冷候选”（不保证 R2/边缘内部冷缓存），随后同 URL 至少 5 次标为“暖重复”。独立校验 raw
CID；在全新离线 Kubo 仓库导入下载 CAR、重建并逐文件比较 SHA-256；单独保留原生产非空 legacy
CID 的下载校验。验证匿名写入/列表拒绝、无效或过期 token、缺失内容与条件请求的既有语义，不通过削弱鉴权改变结果。

对象操作数仅采纳实际平台 traces/查询或可核查遥测；无法取得时明确记为未观测，不得由延迟或本地 counted
binding 推算成真实 R2 操作数。存储证据区分实际 R2 对象字节、CAR 字节和 D1 索引逻辑字段；如没有平台计费字节/索引占用，明确排除该项并解释去重、压缩、旧对象保留的影响。逐项报告中位数、范围及前后比值，明确指出整包下载的任何退化。

发布只用下一未占用 `release-YYMMDD-INDEX` tag，记录准确 commit、Actions
URL、全部检查结果、Worker
version 与流量分配。出现核心源代码缺陷先回报父任务，不在本阶段修改。CAR-only 写入后禁止回滚旧 reader；保留 CAR 读取能力并前向修复。不清除 legacy 数据；只撤销本次创建的短期 smoke
token 和自有 pin，并记录公共内容仍可能保留。原始测量与结论保存在本 outer 的同世界证据文件；只有实际完成的条目才勾选 ledger。

## Acceptance criteria

### D-AC01: 远端内容可用且完整

以获授权环境的真实下载及独立 CID 校验、CAR 文件重建结果，证明新旧数据均可访问，单块范围读取正确。

### D-AC02: 性能与空间取舍可核查

保存可复现的同条件对照结果，证明新格式整包下载不再逐块读取，并报告首字节时间、总耗时与存储成本变化；对任何性能退化给出明确结论，不以本地模拟替代真实 R2 证据。
