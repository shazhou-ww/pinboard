## 外部验证矩阵

以下均为待执行项，不是生产通过记录。必须先将此契约同步到 primary，确认稳定的部署修订，再对明确授权的实际版本运行检查。

| 外部检查             | 应收集的证据                                                        | 通过条件                                                     |
| -------------------- | ------------------------------------------------------------------- | ------------------------------------------------------------ |
| 实际边缘 TLS/HTTP2   | 目标域名、请求协议、证书验证结果和响应头                            | 正常证书验证，原始区块请求可经 HTTP/2 完成，无本地不安全配置 |
| 空 identity CID 探测 | bafkqaaa 的 GET/HEAD 请求、响应状态和元数据                         | raw 选择成功时 200、长度 0、无重定向；HEAD 无体              |
| 内容可用性           | 已存储/缺失的测试 CID，GET/HEAD 与缓存指令                          | 普通缺失 404；only-if-cached 缺失 412；存在内容正常返回      |
| 条件请求             | 测试区块与探测的 ETag、强弱标识、列表、通配符                       | 匹配 304 且无体，不匹配 200；缺失根不误返回 304              |
| 内容协商与拒绝       | format/Accept、q=0、通配符、畸形和缺失选择器                        | 符合已接受协议矩阵的 200/400/406 与 format 优先级            |
| 表示形式与浏览器防护 | 字节、Content-Length、ETag、attachment、CSP、nosniff、CORS 和缓存头 | 元数据正确，GET/HEAD 一致，下载字节与已知内容一致            |
