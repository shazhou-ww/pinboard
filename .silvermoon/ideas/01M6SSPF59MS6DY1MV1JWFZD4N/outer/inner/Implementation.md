# Implementation

本契约承接已接受的构想，不修改 Ideal
World。实施结果与门限证据见[实施证据](./Implementation-evidence.md)，运行与构建边界见[PDF 预览说明](../../../../../docs/pdf-previews.md)。技术依据仍为[技术方案](./ideal/Technical-proposal.md)、[架构设计与复审](./ideal/Architecture-review.md)与[调研证据](./ideal/Research-evidence.md)。

## Steps

### I-S01: 建立有界 PDF 渲染适配层

接入预编译 PDFium
WASM、字体回退和只渲染第一页的像素输出；固定依赖、授权声明、可复现的内存上限产物及校验方式。建立与 R2/D1 无关的只读源输入和独立像素输出，验证即时独占准入、固定回调生命周期、完整组合资源预算及故障隔离，避免直接拼接 PoC。

组合预算收敛为一个 32 MiB 解码内存区与一个 16 MiB
WebP 编码内存区；PDFium 和已有图片解码器按独占会话复用前者。故障或格式切换时清零同一底层内存并重建原生状态，不以“旧实例会立即 GC”作为恢复前提。PNG 分配器的虚拟页计数及胶水初始化修改纳入确定性构建校验。

### I-S02: 接入局部读取与现有预览流水线

组合 UnixFS 文件区间读取、完整块校验与请求内去重缓存，通过 PDFium 渐进加载接口异步补齐依赖。独立限制逻辑文件大小，小文件全读和大文件按需读取共用累计预算；像素编码只做必要抽取，原编排处理忙碌退让、租约、重试与版本过渡，不侵入存储格式或公开协议。

固定 32 MiB 逻辑文件上限、64 次物理块读取、12 MiB 物理总量、8
MiB 逻辑窗口和 64 轮渐进加载；不超过 256 KiB 的文件先全缓存。延后任务保留
`pending`
并退还领取次数。保留源、DAG 成员、出版物与 GC 的原有事务围栏不变；全局预览版本升至 2。

### I-S03: 固化回归测试与使用边界

将代表性 PDF 与确定性生成器转为仓库测试，验证读取收益、像素等价、字体、超限恢复、权限和回收，并更新直接相关文档。避免把本地 PoC 的成功当作线上资源验收。

字体参考来自随仓库字体的独立 FreeType 栅格，运行测试不依赖系统字体或会话路径。图片、文本、目录、公开出版物及路径节点继续使用通用描述；客户端只补充旧 PDF 缓存重验与暂时失败的有界重试可见性，不新增阅读器或修改居中裁切样式。

## Acceptance criteria

### I-AC01: 首页与现有图片行为正确

通过独立参考或人工确认的固定样例证明支持的 PDF 首页正确、WebP 最长边不超过 480px 且不超过 65,536 字节；覆盖旋转与页面边界、嵌入及未嵌入简繁中文、明确的表单/静态外观能力。现有图片、文本和目录预览回归通过，卡片裁切行为不被全局改变。

### I-AC02: 局部读取有收益且保持完整性

对后续页携带大资源的非线性化样例，局部与全量首页像素一致，实际 R2 读取字节数至少减少 75%；小文件与首页重资源样例不承诺节省。测试同时证明相同块的并发读取合并、损坏块拒绝，以及重复块引用、逻辑大小、物理读取、缓存和渐进轮次预算生效。

### I-AC03: 失败可恢复且完整检查通过

组合测试证明加密、不可用源、分配失败、WASM 异常及同步缓存缺失不会发布成功描述，且故障处理不污染后续正常任务；固定回调/缓存释放、忙碌不耗失败次数、截止时间、租约围栏、版本过渡及客户端恢复可见性均有断言。实施完成前证明完整执行链的资源预算可行，部署阶段再验证线上 CPU 与平台内存表现；现有生命周期和授权回归、仓库要求的
`pnpm check` 均通过。
