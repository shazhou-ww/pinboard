# Deployment

本契约是准备阶段的外部验证初版；本次只记录计划，不授权部署、发布标签或执行生产迁移。

## Steps

### D-S01: 在隔离环境验证资源与可用性

以实施阶段已通过组合资源验证的候选为前提，在获准的 Cloudflare 非生产环境使用合成或公开样例，验证字体、渐进读取、WebP 编码、包体积、实际 CPU 和总 isolate 内存表现，确认并发与失败恢复不影响其他请求。不能等到本阶段才首次组合运行渲染器和编码器。

### D-S02: 获准后发布并检查真实入口

仅在用户明确授权生产发布后，按[部署指南](../../../../docs/deployment.md)执行既有标签驱动流程，核验节点缩略图、历史 PDF 重新生成、失败提示、原有管理操作与回收行为；如果出现资源回归，执行已确认的回退方案。

## Acceptance criteria

### D-AC01: 平台资源预算得到外部证实

通过目标环境的构建产物、请求指标和平台日志证明组合方案满足实际包体积与 CPU 配额，代表性并发及超限恢复测试未造成 Worker 资源耗尽；明确测量能力及未覆盖范围，不用 WASM 堆容量代替总内存结论。

### D-AC02: 发布后用户结果可观察且可回退

经授权发布后，在真实入口验证支持样例显示一张首页缩略图、失败样例明确提示且原内容管理可用；记录部署版本、验收样例、旧版预览更新及回退检查证据，不以本地测试代替外部结果。
